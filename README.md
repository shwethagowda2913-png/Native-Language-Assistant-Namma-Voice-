# 🗣️ NammaVoice – Native Language Assistant

A Python-based intelligent voice assistant that enables users to communicate in their native language using speech and text. The application provides voice interaction, language support, and AI-powered responses through a simple and user-friendly interface.

---

## 📌 Features

- 🎤 Speech-to-Text Conversion
- 🔊 Text-to-Speech Response
- 🌐 Native Language Support
- 🤖 AI-Based Question Answering
- 👤 User Authentication
- 💾 SQLite Database Integration
- 🔗 REST API using Flask
- 🖥️ Simple and Interactive User Interface

---

## 🛠️ Tech Stack

| Category | Technologies |
|----------|--------------|
| **Programming Language** | Python |
| **Backend** | Flask, Flask-CORS |
| **Frontend** | Python (Tkinter) |
| **Database** | SQLite |
| **Libraries** | Requests, JSON, hashlib |

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shwethagowda2913-png/Native-Language-Assistant-Namma-Voice-.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Native-Language-Assistant-Namma-Voice-
```

### 3️⃣ Install Dependencies

```bash
pip install flask
pip install flask-cors
pip install requests
```

Or install everything together:

```bash
pip install flask flask-cors requests
```

### 4️⃣ Run the Backend

```bash
python BACKEND.py
```

### 5️⃣ Run the Frontend

```bash
python FRONTEND.py
```
